## What This Is

A collection of **interactive, browser-based study tools** covering OLS regression topics from Gordon's *Regression Analysis for the Social Sciences* (2nd ed.). Each module teaches concepts step-by-step with live Stata output examples, interactive sliders, and guided practice questions with detailed feedback.

**This does not replace your personal study time.** It's designed to supplement your reading, lecture notes, and problem sets — not substitute for them.

## What's Inside Each Learning Lab

Every module follows the same learn-first structure:

```
📖 Concept Explanation      →  Plain-language teaching with formulas
🔧 Interactive Explorer     →  Sliders and calculators to manipulate ideas
📋 Stata Output Walkthrough →  Real output you learn to read and interpret
✏️ Guided Practice          →  MCQ, numerical, and written interpretation questions
💬 Teaching Feedback        →  Detailed explanations whether you're right or wrong
↻  Unlimited Retries        →  Every question can be attempted again
```
